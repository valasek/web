# Site Profile API

This unauthenticated, read-only API describes Stanislav Valasek's coaching,
mentoring, and training practice.

## Endpoints

- `GET /api/site-profile.json` returns the public profile and service links.
- `GET /api/status.json` confirms that the static API deployment is available.

The OpenAPI 3.1 description is available at `/openapi.json`.
